## 2. 招募 20 人：筛选比人数重要

**优先找有做饭习惯的家庭**（PRD P0 画像）：自己或家人负责买菜做饭、一周至少下厨几次、冰箱里常有剩菜。这类人才能真正回答「会不会每天打开用」。

| 条件 | 说明 |
|---|---|
| 必备 | 有智能手机/电脑、能用**普通浏览器窗口**、愿意连续 14 天、第 14 天愿意导出 CSV 发回 |
| 加分 | 负责家庭买菜做饭、常为「今晚吃什么」发愁、有过食材放坏的经历 |
| 排除 | 只用无痕窗口、经常清 Cookie / 换设备、组织者本人、会收到额外用法指导的人 |
| 余量 | **多邀 2–3 位候补**（P21–P23）。判定脚本样本不足直接给 `INCOMPLETE`，不会替你凑数 |

招募渠道建议：熟人 + 家庭/邻里群 + 做饭/减少食物浪费主题社群。不要付费买样本、不要找同事凑数——测的是真实行为，不是注册数。

## 4. 分配匿名编号 + 教会录入食材

### 只教一件事：怎么把食材录进去

**教学必须在 D1 首次分发时一次性做完，且只教「录入食材」**。开跑包 §2 明确写了：分发后不要再做用法教学、不要发问卷、不要引导「今天记得去点某个功能」，否则测到的就不是真实行为。

给参与者的一小段（发链接时一起发）：

> 第一次打开后，点顶部「我的冰箱」→「+ 手动添加」，把家里几样常吃的东西和大概保质期填进去就行（比如青菜 3 天、鸡蛋 20 天）。
> 「拍照识别」是可选演示功能，默认走本地模拟，不上传照片；不想用就手动加。
> 之后你按自己习惯正常用就好，我不会再教你别的，也不会提醒你点哪个功能 😄

其余 8 个视图、周菜单、剩菜盒、备份导出**都不要教**——它们是留给真实行为去检验的。
